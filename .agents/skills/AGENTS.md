# AGENTS.md — skills

`skills/` is the recognized interoperability sublayer for reusable agent procedures.

Read this contract when a goal requires a reusable procedure, then read and follow the selected
package's own instructions. This contract routes to packages; it is not a skill package itself.

## Authority

A package is a reusable procedure, never project truth and never a grant of permission. Finding
one does not authorize work beyond the current user request, project instructions, and task
scope. A package's own `AGENTS.md` or `SKILL.md` governs how to carry out that package's
procedure; it never raises this ceiling, overrides project instructions, or supersedes this
contract.

## Discovery

Discover packages by reading the direct children of this directory and each package's own entry
point. This contract names no required manifest, index, or common format: what a package exposes
to whatever host loads it is that package's own business.

## Ownership and coexistence

The managed contract belongs to the portable agent layer. Each package remains owned by its
author, installer, or project, and layer updates must not rewrite, relocate, or delete package
contents. Preserve every package, project suffix, and unknown or host-incompatible direct child
alongside this contract — do not classify, hide, or overwrite what this contract does not own.

## Host projection

A host may need its own path or format to reach a package that already lives here. Such a
projection is always a non-owning pointer into this directory, added at the adopting project's
own discretion. It is never distributed as part of this layer and never a second authoritative
location; content is not duplicated to satisfy one.

## Provenance

This contract does not require a package to record where it came from or which version is
installed. Nothing here prevents an author from doing so, and nothing here depends on it.
