# AGENTS.md — skills

`skills/` is the recognized interoperability sublayer for reusable agent procedures.

Read this contract when a goal requires a reusable procedure, then read and follow the selected
package's own instructions. This contract routes to packages; it is not a skill package itself.

The managed contract belongs to the portable agent layer. Each skill package remains owned by its
author, installer, or project, and layer updates must not rewrite, relocate, or delete package
contents.

Finding a package does not make it durable project truth or authorize work beyond the current
user request, project instructions, and task scope.

Preserve packages, project suffixes, and unknown direct children alongside this contract. Detailed
skill authority, provenance, host projections or adapters, format, and lifecycle are deferred to
a later skills-specific decision and are not defined here.
